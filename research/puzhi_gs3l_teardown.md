## 3. 结构拆解 / 组件拆分（BOM 级）

> 该产品为"涡轮风扇 + Peltier 制冷"复合结构，内部是典型的消费电子分层堆叠。按拆机顺序拆分：

```
壳体系统（外观件）
├── 前壳（出风口侧，含进风栅格/涡轮风道造型）
├── 后壳（进风口侧，含挂绳孔）
├── 侧键软胶/按键帽 ×2（风速键、制冷键）
├── 底座支架（折叠脚，180° 旋转，含阻尼转轴件）
└── 五金：十字螺丝 ×4–6、防滑脚垫、Type-C 塞

风道系统（性能核心）
├── 涡轮扇叶（离心式，7–9 片，高速动平衡）
├── 无刷电机（13500 rpm 纯铜线圈，轴径 ~3mm）
├── 导风罩/蜗壳（决定出风速度与噪音）
└── 出风格栅（防异物）

制冷系统（差异化核心）
├── 半导体制冷片 TEC1-03104 / 同等规格（4A @5V，ΔT 最大 ~60°C）
├── 冰敷冷板（铝/不锈钢，与冷面贴合，接触皮肤）
├── 热面散热：铝散热片 + 小风扇（与主风扇共用风道） 
└── 导热硅脂/导热垫（冷面-冷板、热面-散热片之间）

电控系统
├── 锂电池 4000mAh（聚合物软包，3C 认证，温控保护）
├── 主控 PCB（无感 FOC/方波驱动芯片 + 升压/充电管理 + LED 数显驱动）

├── 挂绳、说明书、Type-C 线、彩盒/吸塑
```

## 4. 从"看产品"到"做产品"：工业设计全流程

**先说清一件事**：淘宝商品页没有、也不会给你 3D 模型。拿到工程级 3D 的合法途径只有两条——买样机拆解逆向重建，或找源头工厂拿 ODM 图纸。下面的流程是"自己做一个同类产品"的完整路径：

### 阶段 0：竞品逆向（2 周）
1. 买 3 台样机：普芝 GS3L（¥77）+ 北丫（¥131）+ 国货严选走量款（¥29）——覆盖三个价位，对比"贵在哪"。
2. 拆解建档：称重、测尺寸（卡尺）、拍照拆机（每个部件留档）、记录螺丝规格/装配顺序。
3. 热/声测试：实测风速（风速仪）、噪音（分贝计）、电池续航、制冷片表面温度（红外测温）。
4. 输出：逆向 BOM + 结构分析报告 + 竞品卖点对照表。

### 阶段 1：ID（工业设计，2–4 周）
- 概念：定形态（手持棒式 vs 折叠式 vs 挂脖）、定场景（户外/桌面/通勤）。
- 草图 → 2D 效果图 → **3D 概念建模**（Rhino / Fusion 360 / Blender 均可），确认比例与 CMF。
- CMF：ABS 基材 + 配色（普芝用象牙白/浅黑/薄荷绿三色 + UV 高光或哑光）、材质纹理（晒纹）。
- 人机：握持直径 ≤45mm、按键位置拇指区、冰敷板贴脸/贴腕角度。

### 阶段 2：MD（结构设计，3–6 周）
- 在 ID 曲面壳内做**内部堆叠**：电池 → PCB → 电机+涡轮 → 制冷模组 → 风道。
- 关键设计点：
  - 风道：涡轮风机蜗壳设计（螺旋形流道）决定风速和噪音，是这台机器的"心脏"；
  - Peltier 热管理：**热面必须把热量排掉**（散热片+风道引出），否则制冷片降温效果崩掉——这是伪制冷和真制冷的分水岭；
  - 防水 IPX4：按键处硅胶密封 + 壳体超声波焊接或密封圈；
  - 折叠转轴：180° 阻尼设计（扭簧 + 摩擦片），桌面站立重心校核；
  - 数显：LED 数码管窗口透光（半透黑 PMMA 装饰件）。
- 输出：可制造性分析（DFM，和模具厂一起做）、装配公差（尺寸链）、跌落/寿命评估。

### 阶段 3：手板 → 验证（2–4 周）
- 3D 打印/CNC 手板，装机测试：风量、噪音、制冷温度、续航、跌落。
- 过认证（小风扇一般不需要 CCC 整机认证，但**含锂电池必须过 CQC/UN38.3 电池认证**，上飞机需 3C 标识）。

### 阶段 4：开模 → 试产 → 量产（6–10 周）
- 注塑模具：外壳 4 件 + 扇叶，模具费约 ¥6–15 万（普芝这种小件双色模更贵）；五金/转轴件开冲压模或直接标准件。
- T0 试模 → 改模 → T1 → 小批量 200–500 台试产 → 全检 → 量产爬坡。

### 阶段 5：包装 + 上架
- 彩盒设计、说明书（多语言如果出海）、详情页摄影/渲染图（用阶段 1 的 3D 模型直接出渲染图，省摄影费）。

### 5.3 对接流程（以模式 B/C 为例）
1. **筛厂**：1688 找工厂页搜"小风扇工厂"，筛条件：所在地（深圳/东莞）、认证（工厂实拍/验厂报告）、星级（四星+）、支持 OEM/贴牌。
2. **询价**：发"RFQ 询价单"：目标价、MOQ、交期、认证要求（电池 3C/UN38.3）、可否改颜色/印刷/包装。一次发 5–10 家对比。
3. **寄样**：付样品费，拿到手拆解对比（和阶段 0 的竞品拆解对照，验"真制冷/真风量"）。
4. **验厂**：实地或视频验厂（产线、注塑机台数、电池供应商、质检流程）；1688 看店铺"品质达标率/48h 揽收率/回头率"作为线上背书。
5. **报价单核对**：让工厂出含税/不含税、含运费报价；模具费单独谈（公模免模费，私模收模费）。
6. **签约**：ODM/OEM 合同 + 保密协议（NDA）——图纸、BOM、供应商名单都算你的资产；约定模具所有权归你。
7. **NPI**：试产 100–300 台 → 外观/功能全检 → 抽检老化 → 正式下单（首单建议 500–2000 台，周期 15–30 天）。
8. **品控**：工厂出货前驻厂 QA 或第三方验货（如验货宝），抽 AQL 2.5。

## 6. 我们做这个产品的打法建议

1. **不建议从零开私模做"普芝同款"**——市场已红海，结构标准化，公模+贴牌就能打。除非你有明确品牌资产或渠道，否则先走 **模式 A/B**（一件代发测品 → 现货改款）。
2. **差异化三个方向**（普芝的短板即机会）：
   - **噪音**：普芝差评核心是"大风力=大噪音"。做"9000 转静音 + 真制冷"（QS3 轻音款 ¥79.9 已验证此方向有市场）或改进蜗壳风道降噪；
   - **制冷真实性**：把"真 Peltier 直降温度"做成可感知的（数显实时温度、冷板温度 ≤8°C），这是 2 万+ 走量款做不到的，也是 ¥77 vs ¥29 的核心溢价点；
   - **形态**：挂腰款（工地/户外场景，¥56–59 档已有量）、充电宝二合一（Mave ¥169 证明了高客单可行性）。
3. **⚠️ 外观专利风险**：普芝明确声明外观为其原创专利并已起诉仿冒（详情页防伪页）。**不要照抄普芝外观做同款**——要么外形差异化（同结构不同外观不侵权），要么上架前先做外观专利检索（佰腾/soopat），有风险就绕开。
4. **定价**：如果对标普芝，终端 ¥69–89 之间（比它低 10% 或同价加赠品）；出厂成本控制在 ¥45–55。
5. **先验证再投入**：第一轮用 1688 一件代发 + 自己的详情页/短视频跑 2–4 周，测点击率和转化，数据好再谈起订改款。**不要一上来就压货。**
6. **合规**：含锂电池产品必须：电池 3C/UN38.3、产品 3C（上架需要）、详情页参数如实（避免"制冷空调"夸大宣传被举报）。

## 7. "先出图 → 自建模"的完整流程

你的思路（先有图、自己建模、再对接）是标准做法，具体拆成 5 步：

### 7.1 概念图（这一步用"图"而不是"3D"）
目的：定方向和卖点，给建模/工厂看"我们要做成什么样"。三条路径按成本选：

| 路径 | 成本 | 产出 | 适用 |
|---|---|---|---|
| **AI 概念图**（即梦/Midjourney/豆包） | 免费～¥200/月 | 3–5 张风格稿，快速试方向 | 起步定风格首选 |
| **ID 设计师手绘+效果图** | ¥3,000–8,000/套 | 专业 2D 效果图 + CMF 标注 | 有预算、要发给工厂的正式稿 |
| **直接从 3D 渲染** | 0（自己建模后） | 真实感最强 | 建模完成后替代概念图 |

> AI 概念图模板（可直接用）：`产品摄影风格，手持式半导体制冷小风扇，流线型人体工学机身，正面 LED 数显，金属冰敷板，薄荷绿+象牙白配色，产品置于浅色渐变背景，柔和影棚光，超高清商业渲染图`——多生成几个方向挑一个，再让 AI 细化。

### 7.2 设计规格书（把图变成参数）
概念图定稿后，写一页规格书：外形尺寸目标（参考普芝 168×53×47）、重量 ≤200g、风量 ≥10m/s、转速档位、制冷板温差、电池容量、防水等级。**这一页是后续所有沟通（建模/手板/模具/报价）的唯一事实来源。**

### 7.3 自己建模
- 软件：**Blender（免费）** 足够出外观和渲染图；结构/工程级建议 **Fusion 360（个人免费）** 或 Rhino。
- 分步：外观曲面 → 壳体分件（前/后壳+按键+支架）→ 内部堆叠（电池 2×18650、涡轮风机、TEC 制冷片、PCB 按实际尺寸建模）→ 出工程图/STL。
- 自己建模后导出：**STEP/STP**（给模具厂和结构工程师，能转工程图）、**STL**（打手板）、**渲染图**（详情页/给工厂看效果）。

### 7.4 手板验证
拿 STL 打 3D 打印手板（¥300–800/件），验证手感、按键位置、风道效果，然后再进模具。**别跳过这一步**——模具改一次就是几千到几万。

### 7.5 出图给工厂
把概念图 + 规格书 + STEP 模型发给工厂，要求按你的设计报"模具费 + 单价 + 周期"。这就是下面第 8、9 节要对接的人和花的钱。
