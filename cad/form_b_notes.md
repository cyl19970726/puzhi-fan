> 建模脚本：`cad/build_form_b.py`（独立，未改动 build_render.py / build_form_a.py / composite_renders.py / export_glb.py）
> 渲染：`cad/renders_form_b/{cream,green}/{front,three_quarter,side,back,top}.png`（1024×768 RGBA 透明底，双 CMF 各一套五视图）

> 坐标约定：X=高度，Y=前后（前=+Y），Z=左右（右=+Z）；支脚 10mm + 机身 150mm = 总高 160mm；机身 200(Z)×150(X)×120(Y)mm

## 2. 形态决策记录（含专利规避条款逐条落实）

**patent_avoidance.md §3 方向 B 节四条硬约束 + 两条拉开要求，逐条落实证据：**

1. **"网罩用整面均匀细网（覆盖正面 80%+），禁止偏置大圆喇叭区+调频刻度窗构图"** → `FrontMesh` 190×128mm 居中满铺，覆盖正面 81%（(0.190×0.128)/(0.200×0.150)=0.811），无任何偏置圆区；网面为均匀菱形编织（两组正交 2.2mm 周期 Wave 相乘），无中心喇叭构图。证据：`renders_form_b/*/front.png`——正面只有一面均匀细网。
2. **"取消任何调频刻度/波段标识装饰"** → 全模型无刻度带、无波段字符、无指针；旋钮上仅一条档位指示刻线（功能性标记，非调频刻度窗）。
3. **"单颗大旋钮（居中下沿或顶部），禁止双旋钮+刻度窗三联布局"** → 顶部仅 1 颗 Ø42 大旋钮居中偏后 + 1 颗制冷功能键（Ø15，非旋钮，无调节语义）；不构成"双旋钮+刻度窗"三联。证据：`renders_form_b/*/top.png`。
4. **"TEC 热排从背部/顶部出，不在侧面开喇叭式圆网"** → 热排为顶部后缘 6 横槽格栅（`HotVent`），进风在背部下段横条格栅（`IntakeGrille`）；两侧面完全干净（`side.png` 可见侧面只有腰线与支脚）。
5. **"R 角、网罩编织纹样、支脚形态与猫王/Divoom 拉开"** → ① R16 大圆角+平顶（猫王系多为小 R+顶部提手/拱顶）；② 网罩为金属菱形编织细网（猫王=布艺/横条纹，Divoom=圆孔点阵）；③ 支脚为垂直 squat 圆脚（猫王=外撇金属锥脚）。
6. **数显位置避开收音机构图** → 小圆数显窗放**顶面前缘左**（非正面——正面整面网无任何开窗），与制冷键前缘右对称，不构成收音机"刻度窗居中"布局。

**其余形态决策：**

7. **数显躺顶面而非正面**：正面让位给 80%+ 网罩覆盖率（硬约束），顶面数显同时符合"桌面俯视操作动线"——人坐位高于机器，低头即读出风温度。字形自绘 7 段数码管（纯 mesh，可整体命名导出 GLB），俯视图 up 向量使字符正立。
8. **腰线藏在网罩下沿之下**：装饰腰线（胡桃木/黄铜 5mm）+ 薄荷细线（1.6mm）整体置于 x=0.013–0.020，低于网罩下沿 x=0.021——第一轮腰线压在网罩上（可见网罩被木条截断，可见网面跌破 80% 且构图脏乱），已修。正面网罩保持"整面"，腰线在侧/背面读出。
9. **顶部功能分区**：前缘左=数显、中=大旋钮、前缘右=制冷键、后缘=热排格栅。旋钮与热排间距 2mm（旋钮后缘 y=-0.033，热排前缘 y=-0.034）——首轮几乎相贴，接受（真机旋钮有下沉基座），记录为已知不足。
10. **热排造型化**：6 条 Z 向横槽+深色凹腔，与背部进风横条同族语言但位置/功能区分（顶=热排，背下=进风），"独立热排"成为可读设计元素（架构 ADR-1 收益）。
11. **CMF 双方案**：① 奶油白（0.955,0.940,0.905 哑光）+ 胡桃木纹旋钮/腰线/支脚/数显压圈（Noise→双棕 ramp 概念级木纹）+ 暖青铜网罩；② 墨绿（linear 0.022,0.062,0.042——首轮 0.105 档在 Filmic 下洗成浅鼠尾草绿，已修）+ 黄铜滚花旋钮/腰线/支脚/压圈 + 深炭网罩。薄荷绿细线双方案共用（品牌基因）。
12. **相机/灯光**：沿用形态 A 三点 studio 光（Key 4W / Fill 1.5W / Rim 2.5W）+ Filmic + 透明底；俯视图 up=(0,-1,0) 使产品前脸朝画面下方。

## 3. 已知不足（下一轮迭代候选）

1. **网罩为 shader 编织纹理（bump），非真实冲孔**：480px 预览有轻微摩尔纹，1024px 原生分辨率下为干净细网格（已裁切核验）；开模前需按真实金属网孔径重建。
2. **数显无辉光泛光**：EEVEE 5.x 无 bloom，发光仅材质自发光；海报级效果需合成器 Glare 节点。
3. **木纹为 Noise 近似**：无真实木纹导管走向；概念阶段足够，CMF 打样前需换真实木纹贴图。
4. **黄铜材质在 EEVEE 白色 World 下偏"哑光金"**：金属反射缺 HDRI 环境，黄铜偏土黄；如需海报级金属感挂 studio HDRI。
5. **旋钮与热排净距仅约 1–2mm**：真机需旋钮基座下沉或热排后移；当前为概念可读性让步。
6. **格栅为贴面造型**：热排/进风是"凹腔+贴面条"，非真实贯通孔；开模前按 IF-2 密封要求重建真实风道。
7. **前壳分模线未表达**：网罩四周与机身无缝隙线；真机网罩为可拆件（旋扣/磁吸）未建模。
8. **内部架构未建模**：M2 电池/M4 风机/M5 鳍片均无内部件，GLB 仅外观；工作台"拆解视图"需另建内部堆叠。
9. **Type-C 仅深色凹块**：无金属舌片细节。
10. **皮质/金属提手（方向 B 可选项，露营场景）未建**：等 Q1 拍板后补。
