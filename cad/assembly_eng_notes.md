## 2. 与概念级（build_core.py）的差异

1. **格栅：贴面造型 → 真孔+嵌条**。概念级是"凹腔浅坑+贴面格栅条+深色假腔底板"；工程级外壳 boolean 开贯通孔，格栅条嵌在孔内，条间是真实开口（后视图可直接看到风机、PCB、鳍片）。
2. **风道：示意 → 贯通腔体**。概念级无实际风道壁；工程级有完整冷风道四壁（含静压腔→出风口收缩斜顶）与热风道导流板，流路 后进风→风机→冷鳍→前出 / 后进风→热端→右侧排 全程有壁面约束。
3. **中隔板：单片 → L 形全长**。概念级只在 TEC 前有一小段隔板；工程级主板+前横板把冷/热腔沿全风道长度物理分断（ADR-1），接触边全部带 EVA 槽。
4. **外壳：实体圆角块 → 2mm 薄壁 tub+盖**。概念级 Body 是实心圆角方体；工程级是拔模薄壁壳体+前壳盖，有分件线、旋扣、螺丝柱。
5. **导风联动：摇臂示意 → 齿轮副+联动杆**。概念级一根摇臂；工程级 28BYJ-48→m0.8 齿轮→扇形齿轮→三曲柄联动杆，啮合中心距按分度圆严丝合缝。
6. **主控 PCB 移位**：概念级 PCB 在热腔（后壁右侧 z=+0.045，布局不合理）；工程级移到冷侧进风后方（z=-0.055）。

## 3. 看图修掉的问题（迭代物证，共 5 轮构建）

- **R1→R2 frustum 法线绕反**：自建锥台网格面绕序错误（法线全朝内），导致 FrontPanel 的出风槽/数显窗 boolean 静默失效（前视一片空白）——翻转 6 面绕序后真孔全部生效。Body 的"外反-内也反"差集恰好自洽，是此 bug 最隐蔽处。
- **R2→R3 SkidPad 盖住螺丝沉孔**：底部视图只见 2 个透光点；硅胶垫补 3×Ø8 让位孔。
- **R3→R4 螺丝柱通孔透光**：底部可直视风道底板（daylight through product）；改盲孔（柱顶留 4mm 咬合料）。
- **R4→R5 圆柱轴向系统性错误**：Blender 圆柱默认轴向 Z，而本机坐标 X=高度/Z=左右——电芯、导风板轴/曲柄、步进电机、齿轮轮毂、螺丝柱/沉孔刀具全部用错旋转（电芯甚至沿 X 竖立 65mm 直接戳穿底座，底部视图两个蓝点就是电芯底面）。全部改正：电芯/导风轴/电机/轮毂=默认 Z 轴（机器左右），螺丝柱/沉孔=(0,π/2,0)（机器竖直 X）。改后底部 3 个干净盲孔、电机正面朝右、导风轴正确穿入风道侧板轴承孔。概念级 build_core.py 的电芯旋转同样错误（沿袭未改旧文件，此处记录）。
- 验收通过项：后进风孔直视风机/PCB/冷鳍；出风槽直视导风板+冷鳍边缘（合理掠射视线，非漏风）；右侧孔直视铜鳍；齿轮副齿形/啮合可读；工作台④爆炸+高亮正常。

## 4. 仍未做（属于 ODM/开模阶段，本模型不表达）

1. **公差体系**：所有配合（旋扣 12mm 钩片 vs 10mm 槽、导风板轴 Ø4 vs 轴承孔 Ø5、玻璃搭接 2mm）均为名义尺寸，未给公差带；开模前需按 ±0.05~0.1mm 注塑精度出公差分析。
2. **材料收缩率**：几何按名义尺寸建模，未按 ABS/PC 收缩率（~0.5%）放模；模具厂放缩水时整体缩放即可，本模型不影响。
3. **真实 FEA/热仿真**：TEC 40W 级热流、鳍片间距（冷 4.4mm/热 10.3mm）、风机 P-Q 曲线匹配均为布局示意，未经 CFD/热仿真验证；跌落工况电池仓强度未做 FEA。
4. **出模细节**：斜顶/滑块位置、浇口、顶针痕、加强筋网（壳体内壁目前光板）、超声焊线（§8 提到的超声焊仅记录在案，几何未做焊接筋 0.3×0.6mm 三角筋）、止口配合段差。
5. **电机仓独立密封**：步进电机穿仓豁口目前直通热腔（量产件应给电机独立仓+泡棉，此处豁口保留供走线/装配示意）。
6. **扫风行程动画**：导风板仍为静态 15°（同概念级遗留 #2），±30° 行程未做关键帧。
7. **走线/线束**：JST 到 PCB 的线束路径、Type-C 到充电 IC 走线未建模。
8. **漏风率 <5%（IF-2）的量化验证**：EVA 槽/棉条为几何特征表达，未做气密仿真或风洞实测。
