## 1. 竖向堆叠布局（架构 §5.2 轴向塔式，自下而上；X=高度）

```
x −0.026..0    M1 底座 Ø110：配重袋(钢盘 Ø88×3 沉入) + 3×(Ø2.5通孔+Ø5沉孔)
               + 整圈硅胶圈(3×Ø8让位) + 背部 Type-C + 摇头电机预留安装位(Ø30+2×Ø2)
x 0.002..0.014 塔底螺丝柱×3（环 r48：内让配重盘 r44，外让内腔；Ø2.5 盲孔留咬合料）
x 0.014..0.084 M2 电池仓：托盘(坐螺丝柱上) + 2×18650 竖放(x0.0185..0.0835, z±0.011 并排)
               + 顶部 strap(2×Ø17 过孔定位电芯肩/正极帽穿出) + 防反插键位+偏心 JST(IF-5)
x 0.088        M3 主控 PCB 横置 + IC（位于冷侧进风路径，进风气流掠过）
x 0.1025..0.1225 M4 Ø80 轴流无刷风机（轴沿 X，向 +X 竖吹；轮毂 0.1025..0.1225）
x 0.125..0.190 M5 L 形中隔板：竖板(y=-0.002) + 底翻边(x=0.125)，TEC 窗 44×44
               —— 风机以上全长分断冷/热腔（ADR-1），风机以下全是冷侧进风路径
x 0.1275..0.1675 M5 TEC 40×40×3.8（法线 Y：冷面 +Y 朝前百叶 / 热面 −Y 朝背部 pill）
               冷端 8 铝鳍（风道沿 Y 朝前）/ 热端 9 铜鳍（风道沿 Y 朝背）
x 0.100..0.168 前向百叶出风口（外壳真贯通孔 + 网罩框 + 横向百叶×10 定角 20°）
x 0.062..0.098 后进风真孔（横条×6）——进风静压腔=电池/PCB 舱
x 0.110..0.168 背部竖向 pill 热排立柱（真孔 z±0.015 + 造型框 + 竖格栅×5）
x 0.190..0.203 顶部死区：35° 斜面数显窗(真孔 26×44+玻璃+卡扣+遮光筋 IF-4)
               + 顶部后区旋钮/制冷键/电位器
```

**风道**（单风机双风道，示意级）：后进风 → 电池/PCB 静压腔（顺带冷却）→ 风机竖吹 ↑ →
隔板底缘分流：前股 → 冷鳍 → 前百叶出风（冷风）；后股 → 热鳍 → 背部 pill 立柱（热风）。
冷风道四壁：颊板 z=±0.021 + 前下防短路挡板(x0.100..0.1275, 挡风机层短路直出) + 顶板(x=0.171)；
热风道：颊板 z=±0.0175 + 顶板。

**与形态 A 核心的布局差异**：
1. A 是卧式 Y 向风路（后进前出一直线），D 是立式 X 向风路（下进、风机以上 90° 折向前后双向出）；
2. A 双风道各有一段独立进风，D 单风机压一个静压腔、隔板以上分流冷热两股（风量分配见遗留 #2）；
3. D 无摇头机构（免步进电机/齿轮副/联动杆——A 的 M1_Stepper/Pinion/Sector/Link 全部不建），导风靠 20° 定角百叶；底座内仅留 Ø30 摇头电机预留安装位（`M1_OscPad`）；
4. 电芯由 A 的沿 Z 躺放改为沿 X 竖放（Ø84 内腔并排 36mm ✓，架构 §5.2 的塔式排布）；
5. PCB 由 A 的冷侧立板改为横置层板（电池仓与风机之间的自然分层）；
6. 数显由 A 的前壳平窗改为顶部 35° 斜面窗（白模沿袭 + 专利规避 #3）。

## 3. 专利规避逐条落实证据（research/patent_avoidance.md §3 方向 D 节）

1. **截面不用正圆 → squircle**：塔身/底座/腰线全部超椭圆 n=4.0 截面（与白模一致强化）。证据：`inspect_base_bottom.png`（底视明确圆角方形非正圆）、`inspect_ext_front.png`（侧棱直线段+大圆角转角）。
2. **网罩不用放射辐条+同心圆 → 横向百叶**：`GrilleLouvers` 10 条横向百叶（Z 向长条、前缘下压 20°），全模型无放射辐条/同心圆/中心毂。证据：`inspect_front_close.png`、`inspect_ext_front.png`。
3. **数显不放正面中上部长条竖显 → 顶部 35° 斜面**：斜面真孔 26×44 + 7 段数码管 "22.0"（出风温度）；正面唯一开口是百叶网罩。证据：`inspect_ext_front.png`（正面无窗）、`inspect_disp_close.png`（斜面数显）。
4. **塔身-底座顺滑一体，避免球头+圆盘两段式**：塔身 loft 底环 Ø110 与底座顶面等径，45mm smoothstep flare 内收 Ø90，轮廓一条连续曲线。证据：`inspect_ext_front.png`/`inspect_ext_back.png` 侧轮廓。
5. **TEC 热风独立后排格栅造型化**：背部 58mm 高竖向 pill 真孔 + 凸 1.5mm 造型框 + 竖格栅×5，与进风横条方向正交，是背面第一视觉元素。证据：`inspect_back_close.png`、`inspect_ext_back.png`。
6. **薄荷绿腰线作附加区分层**：`Band` 整圈腰线在 flare 结束处（x=0.052），形状级区分之外的加成层，不单独承担规避。
7. 硬性要求照旧：本模型为预检索级规避，开模前必须送代理所与在权外观（含 2026 年新授权 4 件）逐件调图比对。

## 4. 看图修掉的问题（迭代物证，R1–R8 + 9 轮定位调试）

- **R1→R2 材质空槽崩溃**：boolean 刀具（无材质）给目标壳体留下空材质槽，切面引用空槽=丢材质，ghost 材质替换时 `materials[0]` 为 None 直接崩溃（GLB 已导出 37 节点但渲染中断）。修：新增 `fill_empty_slots()` 用本件首个非空材质回填所有空槽（A 的 frustum 绕序教训的姊妹问题：boolean 与材质槽的隐性交互）。
- **R2→R3 爆炸中部拥挤/电芯不可读**：PCB/风机/TEC 三层间距不足糊成一团；18650 被电池仓侧壁挡住。修：全表拉开爆炸间距（电池仓 −0.075、电芯 ±Z 0.075 侧弹出、PCB/风机/TEC/隔板沿 +X 梯次 0.035/0.10/0.16/0.24）。
- **设计自查（R3 前）两处干涉**：① 螺丝柱原环 r32–r41 全部落在钢配重盘 r44 内（螺钉穿钢盘）→ 柱移 r48 环（内缘 r44 切配重盘、外缘 r52 让内腔 flare r52.9）；② 底座沉孔原切在 x=−0.024（硅胶圈层，底座底面在 −0.021）→ 沉孔对齐 −0.019。另：螺丝柱原高 x≤0.018 时柱顶 r52 超出 flare 外皮 r51.5 → 柱高降至 0.014，电池仓/PCB 层整体上移适配。
- **R4→R5 隔板密封肋穿出外皮**：后视可见一条横线+侧壁凸点——矩形直肋/翻边全宽（z±0.041）在 squircle 转角区穿出外壳（squircle 壁面随 |y|/|z| 内收，角部腔体比中部窄）。修：竖板 z±0.038、翻边 z±0.028、侧肋收敛 z0.038..0.042、顶肋降至 x0.190..0.194，全部只嵌壁厚内不穿外皮。
- **R5→R6 背部 pill 两侧对称小黑点**（最顽固的一例，9 轮定位）：面 dump/射线/单件渲染/逐件隐藏二分——隐藏 `M5_EVA` 黑点消失。根因：`eva_rib_bk` 是直条（y −0.04275..−0.04365 恒定），但 squircle 背面外皮在 |z|≈0.026 处已内收到 y=−0.0436，棉条端部穿出外皮 ~0.1mm（两个黑点正是棉条两端）。修：翻边后肋 z±0.028→±0.024、EVA z±0.0275→±0.018 且 y 收到 −0.04285..−0.04375（全程在外皮内侧 ≥0.9mm，仍凸出肋面 0.75mm 表达压缩量）。教训记录：**squircle 壳体内侧的任何直条状密封件，长度必须按外皮曲面内收校核端部**。
- **验收通过项**：后视不透光的干净外皮（poke-through 全清）；pill 孔直视铜鳍、进风孔直视 PCB/电芯（真孔）；百叶缝直视冷鳍；底部 3 沉孔+硅胶圈干净；斜面数显+旋钮+制冷键顶部成簇；爆炸图 电池/PCB/风机/TEC/隔板/数显 竖向分层可读无穿插；GLB 37 节点 extras 全齐。

## 5. 仍未做（属于 ODM/开模阶段，本模型不表达）

1. **单风机双风道分流为布局示意**：冷热风量分配、热端风量是否足够（TEC 40W 级）未经 CFD/热仿真；量产或需热端独立小风机（腔内容积允许，见 §1 风道注）。
2. **隔板顶边与穹顶的贴合**：隔板顶边平直（x≤0.194），与塔顶穹顶内面间有约 5mm 月牙间隙（穹顶曲面未放样贴合）；EVA 仅表达在直边上，量产需泡棉补偿或隔板顶部仿形。
3. **公差体系/材料收缩率**：旋扣 12mm 钩片 vs 10mm 槽、strap Ø17 孔 vs 电芯 Ø18 肩、玻璃 2mm 搭接均为名义尺寸（同 A 遗留 #1/#2）。
4. **塔底壁螺钉过孔未开**（螺钉从底座穿入塔底壁+螺丝柱为示意，同 A 口径）；**走线/线束未建模**（顶部电位器到 x=0.088 PCB 的长距走线、JST→BMS→PCB 线束仅记录）。
5. **出模细节**：斜顶/滑块、浇口、顶针痕、壳体内壁加强筋网、超声焊线、前后壳止口定位扣/段差（目前仅 1.1mm 搭接示意）均未做（同 A 遗留 #4）。
6. **摇头预留位仅为安装盘**（Ø30+2×Ø2）：轴承/滑环/限位绕线选型未做（IF-1 若启用摇头款再议，ADR-3 首选限位绕线）。
7. **百叶 20° 定角的风向验证**：下压百叶抬风向人脸为经验设定，未做气流仿真；俯仰角开模前可调。
8. **热排 pill 竖格栅为直条嵌装示意**，与背面曲面的贴合为概念级。
9. **数显 EEVEE 无 bloom**（同白模遗留）；斜面窗防尘防水等级未表达。
10. **正式 FTO 未做**（§3 规避为预检索级，退出条件同白模）。
