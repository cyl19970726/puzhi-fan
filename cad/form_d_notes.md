# LiteCool S1 — 形态 D「塔·认真版」3D 概念模型验收记录 v1.0

> 建模脚本：`cad/build_form_d.py`（独立，未改动 build_render.py / build_form_a.py / build_form_b.py 及其 composite/export）
> 渲染：`cad/renders_form_d/{front,three_quarter,side,back,top}.png`（768×1024 竖幅 RGBA 透明底）
> 白底合成：`cad/renders_form_d_white/`（含 contact_sheet.png），脚本 `cad/composite_form_d.py`
> GLB：`cad/form_d.glb`（15 个命名 mesh，已解析 GLB JSON 块核验节点名一致），脚本 `cad/export_form_d.py`
> 设计依据：`design/form-directions.md` §5 方向 D；专利规避硬约束 `research/patent_avoidance.md` §3 方向 D 节；堆叠尺寸链 `architecture/product-architecture.md` §5.2
> 坐标约定：X=高度，Y=前后（前=+Y），Z=左右；底座 26mm + 塔身 204mm = 总高 230mm；塔身截面 squircle 超椭圆 n=4.0（Ø90），底座 Ø110

## 2. 形态决策记录（含专利规避条款逐条落实）

**patent_avoidance.md §3 方向 D 节六条规避设计，逐条落实证据：**

1. **"截面不用正圆——squircle/圆角矩形"** → 塔身与底座均为超椭圆 n=4.0 截面（v3.0 n=3.0 基础上强化，正面更平、转角更方），第一眼与"正圆柱塔+正圆网罩"主流注册组合拉开。证据：`renders_form_d/top.png`——俯视图明确是圆角方形而非正圆；`front.png` 侧棱为直线段+大圆角转角。
2. **"网罩不用放射状辐条+同心圆公版纹样——横向百叶式或非均匀参数化开孔"** → `Grille` = 10 条横向百叶（Z 向长条、前缘下压 20°），凹腔嵌装；全模型无任何放射辐条/同心圆/中心毂（v3.0 的 GrilleBar_0..7 放射方案彻底弃用）。证据：`renders_form_d/front.png`、`three_quarter.png`——正面只有一组平行横百叶。
3. **"数显不放正面中上部长条竖显——出风温度大数显放顶部斜面或正面下段独立视窗"** → 选**顶部 35° 斜面**（选择理由见下条）：`DisplayGlass` 44×26mm 独立黑视窗+7 段数码管 "22.0"（出风温度，非档位），位于塔顶前坡，正面中上部无任何开窗/竖显。证据：`renders_form_d/front.png`（正面塔身仅百叶网罩一个开口）、`top.png`（斜面数显正对俯视）。
4. **"塔身-底座顺滑一体，避免球头+圆盘两段式"** → 塔身为变截面 loft：x=0 处截面 Ø110 与底座顶面等径，经 45mm smoothstep flare 内收至 Ø90 后直通塔顶——侧/斜视图轮廓线为一条连续曲线，无"塔身插圆盘"台阶。证据：`renders_form_d/side.png`、`three_quarter.png`。
5. **"TEC 热风独立后排格栅做造型化设计元素"** → `HotVent` = 背部 58mm 高竖向 pill（长圆角）凹腔+5 竖格栅，是背面第一视觉元素而非隐藏孔；与进风横条格栅方向正交可区分。证据：`renders_form_d/back.png`。
6. **"薄荷绿腰线等表面装饰作附加区分层"** → `Band` 薄荷绿整圈腰线置于 flare 结束处（x=52mm），兼任视觉收腰；与截面/网罩/数显/热排的形状级区分叠加，不单独承担规避。

**其余形态决策：**

7. **数显位置二选一：选顶部斜面，放弃正面下段独立视窗**。理由：① 人体工学——桌面塔高 230mm，坐姿视线从上方 30–50° 俯视，顶部斜面"抬头即读"，正面下段视窗需弯腰且易被桌面杂物/手部遮挡；② 正面构图——百叶网罩是正面唯一主角，正面再开黑窗会回到 v3.0"网罩+小窗"的平庸构图；③ 差异化——斜面数显同时是一个形态级特征（切削出的第五面），比"贴一个窗"更耐专利比对；④ 形态 B 已验证顶面数显的可读性，D 把平面升级为斜面（朝前上 35°，兼顾站立远视与坐姿俯视）。
8. **底座做"两段式配色"读稳重**：21mm 雾白配重主盘 + 6mm 深灰硅胶底圈（微内收 2mm 台阶）——侧/背/斜视任何角度都能看到一圈硅胶=防滑承诺的直接视觉证据（F3，品类差评源的解法）；Ø110 相对塔身 Ø90 的外扩 + flare 收腰让"底盘大、重心低"一眼可读。第一轮 SkidPad 内收 3mm 且埋在底座圆角区完全不可见，已改为当前方案。
9. **网罩百叶下压 20°**：桌面场景人高于机器，下压百叶正好把风抬向人脸方向（功能合理），且百叶片间暗缝在正面/斜视可读（第一轮 480px 即验证）。
10. **顶部功能分区**：前坡=斜面数显，后区=单旋钮+制冷键成簇（制冷键薄荷点=品牌色语义），顶部无多余元素；旋钮 Ø26 带铝顶盖+指示刻线，与形态 A/B 旋钮语言同族。
11. **相机/灯光**：沿用 A/B 三点 studio 光（Key 4W / Fill 1.5W / Rim 2.5W）+ Filmic + 透明底；竖幅构图（768×1024）适配塔形；俯视图 up=(0,-1,0) 使产品前脸朝画面下方、数显字符正立。
12. **CMF**：雾白 #F2EFE9 哑光（roughness 0.45）+ 深灰格栅/胶圈 + 薄荷绿腰线（提饱和+微自发光抗直射光，沿用 A/B 标定值）+ 青色发光数显，哑光小家电感。

## 3. 已知不足（下一轮迭代候选）

1. **数显无辉光泛光**：EEVEE 5.x 无 bloom，发光仅材质自发光；海报级效果需合成器 Glare 节点。1024px 下青色字形略洗白（emission 5.0 偏高），近景可接受。
2. **格栅为贴面造型**：百叶/热排/进风均为"凹腔+贴面条"，非真实贯通孔；开模前按 IF-2 密封要求重建真实风道。
3. **斜面数显窗为贴面件**：DisplayGlass 浮贴于布尔斜面上，近看无装配缝隙/遮光棉细节（IF-4 未表达）。
4. **旋钮/制冷键坐于顶部圆角曲面**：与穹顶曲面的贴合线为概念级（微嵌入），真机需做局部沉台。
5. **前壳分模线未表达**：塔身无上下壳/前后壳分模缝隙；网罩旋扣（IF-3）未建模。
6. **Type-C 仅深色凹块**：无金属舌片细节。
7. **内部架构未建模**：M2 电池/M4 风机/M5 鳍片均无内部件，GLB 仅外观；工作台"拆解视图"需按架构 §5.2 轴向尺寸链另建内部堆叠（Ø84 内腔：18650 并排/Ø80 风机/40×40 TEC）。
8. **侧面偏"干净"**：侧视图只有腰线+硅胶圈可读，所有交互/风道元素集中在前/后/顶——概念阶段是有意为之（正面/背面各一张脸），若评审认为侧面空，可加竖向装饰缝。
9. **正式 FTO 未做**：本模型的截面/纹样/数显位置规避是预检索级（patent_avoidance §3）；开模前必须送佰腾/代理所与在权外观（含 2026 年新授权 4 件）逐件调图比对。
