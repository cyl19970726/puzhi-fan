## 2. 形态决策记录

1. **导风板 = 3 片百叶、下倾 15°**（备选：1 片宽叶）。选 3 片：正面直视时片间深色缝隙是"空调出风口"最强符号，1 片宽叶在近关闭角度会糊成一块板；15° 下倾是挂机待机/制冷常见角度，且桌面场景人坐位高于机器，下倾正好对人。片距 15.5mm、弦长 13mm，保证片间暗缝在正面视图可读（第一轮 16mm 弦长把缝糊死，已修）。
2. **数显放正面右上、做大（52×26mm 窗）**。理由：ADR-5"差异化必须一眼可见"，塔形 v3.0 的 30×14 小窗在 220mm 宽正面上会失衡；右上避让出风口主视觉区，与挂机"右侧显示窗"惯例一致。字形用自绘 7 段数码管（非字体），一是"数码管风格"口径，二是纯 mesh 可整体命名导出 GLB。内容 "22.0"=出风温度常显（交互架构温度优先原则）。
3. **热排 = 两侧竖条凹腔格栅、偏后布置**（备选：背面打孔/背面格栅）。理由：架构 §3.2 要求热端排口朝向侧后（用户 135° 视锥之外、与冷风 ≥90° 夹角）；竖条与后进风横条做方向区分，凹腔+深色底是"室外机散热器"的造型化处理而非随便打孔；偏后布置让侧视图直接读出"热风往后走"。
4. **后进风 = 整面横条格栅放背面中上**。横条方向与热排竖条正交，两个风道口造型上可区分；位置中上对应架构"后进风格栅（上段）→冷端"流路。
5. **底座 = 228×118×16mm 整板滑板座 + 底面整圈硅胶垫**（备选：圆片垫——方向稿 §0 已判死刑）。比机身四向各探出 4mm，前缘大圆角，视觉上"趴"在桌面上；SkidPad 独立成件供工作台标注 F3。
6. **腰线位置 x=30mm（底座上方 14mm）**。上下壳分模线同时也是品牌薄荷线；渲染期发现 3.5mm 厚+低饱和在直射光下不可读，改为 4mm 厚、凸出 2mm、提饱和+微自发光。
7. **旋钮+制冷键放顶部偏右成簇**。旋钮 Ø32 深灰+铝顶盖+指示刻线；制冷键 Ø14 带薄荷标识点（制冷=品牌色语义）。顶部操作符合桌面俯视操作动线，正面保持干净的"挂机脸"。
8. **相机/灯光**：沿用 v3.0 三点位 studio 光（Key/Fill/Rim 面积光瞄准机身中心）+ Filmic + 透明底；Blender 5.1 EEVEE 面积光能量按 v3.0 标定值（4/1.5/2.5W），首轮 60W 严重过曝已修。俯视图单独指定 up 向量使产品长轴水平、前脸朝画面下方。

## 3. 已知不足（下一轮迭代候选）

1. **数显无辉光泛光**：EEVEE 5.x 无 bloom，发光仅材质自发光，近景够用但缺"点亮感"；如需海报级效果走合成器 Glare 节点。
2. **导风板为静态 15°**：扫风行程（±30°）未做关键帧/多状态导出；工作台如需演示扫风，需补 Louver 动画或多角度 GLB。
3. **格栅为贴面造型**：热排/进风是"凹腔+贴面条"，非真实贯通孔——概念阶段足够，开模前需按 IF-2 密封要求重建真实风道。
4. **前壳与机身分模线未做**：FrontPanel 四周与 Body 无缝隙线，近看一体感偏强；真机分模细节（旋扣 IF-3 等）未表达。
5. **Type-C 仅深色凹块**：无金属舌片细节。
6. ~~内部架构未建模~~ → **已补（2026-08-28）**：`cad/build_core.py` 在 A 壳内建了内部核心装配体（M5 热模块 TEC+冷鳍+热端散热器+中隔板 / M4 风机 / M2 电池组 / M3 PCB / 28BYJ-48 导风机构 / 旋钮电位器 / 数显模组，共 16 个内部命名 mesh），产出 `cad/assembly_a.glb`（36 命名节点，extras 带 module/label/爆炸向量）+ `cad/renders_assembly/{assembled,exploded}.png`，已接入工作台④（爆炸滑块+零件高亮+BOM 卡）。格栅/风道仍为概念级造型（同 #3），开模前需按 IF-2 重建真实风道。
7. **mint 腰线在正视图偏弱**：直射正面光下 4mm 线仍细；如需更强品牌露出可加到 6mm 或做凹槽嵌线。
