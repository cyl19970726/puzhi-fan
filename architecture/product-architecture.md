## 3. 热与风道架构（核心子系统，原 design-spec 只有一句话，本章为全新设计）

### 3.1 物理原理约束

TEC 制冷是**热量搬运**：冷端从冷风道吸热 Q_c，热端排出 Q_c + P_elec（电功率全变热）。40×40 TEC1-12705 类在 5V 系统限流下 Q_c ≈ 8–15W，热端排热 ≈ 25–40W。**热端排热能力是整机制冷性能的决定项**，不是制冷片本身。

### 3.2 双风道架构（ADR-1：冷风道与热风道物理隔离）

```
        ┌────────────── 塔身 ──────────────┐
 冷风道: 后进风格栅(上段) → 轴向风机 → TEC冷端铝鳍 → 前导流口 → 人
 热风道: 后进风格栅(下段/侧) → 热端散热器(鳍片+热管可选) → 侧后排出格栅 → 环境
        └──────────────────────────────────┘
```

- **隔离原则**：两风道在结构上分腔（中隔板），热风绝不混入冷风流路——这是"空调感"的物理基础（空调室内机/室外机分家的桌面微缩）。
- **热端排口朝向侧后**（用户 135° 视锥之外），出风方向与冷风呈 ≥90° 夹角，避免热风回流进风端。
- **冷端不贴肤**（N2）：TEC 冷面只给风道鳍片降温，数显显示**出风口空气温度**——真实、可验证（C6）。

### 3.3 热预算与性能推导

| 项 | 数值 | 依据 |
|---|---|---|
| TEC 电功率（电池档/插电档） | ≤10W / ≤20W | 18650×2 放电能力 + 5V/2A 输入 |
| 冷端制冷量 Q_c | 6–10W（电池）/ 12–18W（插电） | COP≈0.6–0.9（小温差工况） |
| 冷风风量（制冷档） | ≈25–35 CFM | Ø80 轴流风机中档 |
| 出风降温理论上限 | ΔT = Q_c/(ṁ·c_p) ≈ **3.5–6°C**（插电）/ 2–4°C（电池） | 与 F1 的 −4°C 目标一致 → F1 在物理上可达但无冗余 |
| 热端排热量 | ≤30W | 热端散热器需 ≥20×60×40mm 鳍片体积，热阻 ≤2.5°C/W |

> **架构结论**：F1（−4°C）成立的条件是插电满功率档；电池档只能承诺 −2~−3°C。详情页必须分口径（C6）。这条推导同时是 R2（降温不达标）风险的第一道防线。

### 3.4 备选方案与否决（ADR-1 完整记录）

| 方案 | 结论 | 理由 |
|---|---|---|
| 双风道物理隔离（选定） | ✅ | 热风不混流，降温可兑现；"独立热排"成为可读的空调设计语言（方向 A 的形态资产） |
| 单风道串联（进风先过热端再过冷端） | ❌ | 进风被热端预热 5–10°C，冷端效率崩塌；soip 等低价款疑似此路线，是其"制冷效果"标签羸弱（69 vs 风劲 219）的结构原因 |
| 冷端直吹无鳍片（TEC 冷面裸露出风） | ❌ | 换热面积不足，凝露风险直面用户 |

## 4. 电子架构

### 4.1 电源树

```
Type-C 5V/2A ──▶ 充电管理IC(带路径管理) ──┬──▶ 18650×2 (7.4V→实际为2P 3.7V, 4000–5000mAh)
        │                                └──▶ 系统母线
        └──(插电时直供)──▶ 系统母线 ──┬─▶ Buck 5V → FOC 风机驱动(≤8W)
                                    ├─▶ H桥/限流 → TEC(电池≤10W / 插电≤20W, PWM)
                                    ├─▶ LDO 3.3V → MCU + NTC 采集
                                    └─▶ 数显模组(LED 数码管)
```

- **路径管理**：插电时负载优先由适配器供电、电池恒流补电——"充插两用、插电解锁 TEC 满功率"（F6）的电路基础。
- **保护**：电池温度 ≥60°C 或出风口 ≤12°C（防凝露）→ 停 TEC，数显报 HI/LO（继承 design-spec §5.3）。

### 4.2 控制状态机（D1）

```
[关机] →旋钮按下→ [开机: 电量2s → 档位显示]
[运行] ├─ 旋转旋钮: 100档无级(风机PWM)
       ├─ 制冷键: TEC 开/关(电池档限功率; 数显切出风温度)
       ├─ 摇头键/遥控: 120°摆动 开/关
       ├─ 保护触发: 凝露(LO)/过热(HI) → 停TEC,闪烁告警
       └─ 低电<10%: 闪烁; 定时(Pro): 1/2/4h倒计时→关机
```

### 4.3 传感器

| 传感器 | 位置 | 用途 | 成本 |
|---|---|---|---|
| NTC ×1 | 出风口中心（冷风道末段） | 出风温度数显（F1 核心） | <¥0.5 |
| NTC ×1 | TEC 热端散热器 | 过热保护 + 散热失效诊断 | <¥0.5 |
| NTC ×1（电池组自带） | 电池包 | 电池过热保护 | 含在电池组 |

> 注意：出风温度 NTC 必须放在**冷风道内、网罩之前**，数显读数才是"出风温度"而非"环境温度"——这是 F1 可验证性（C6）的物理落实，也是防"伪数显"指责的设计证据。

## 6. 交互架构

继承 design-spec §5.5 数显状态表，升级为三原则：

1. **温度优先**：制冷开启时数显默认显示出风温度（不是档位）——差异化承诺必须占据最高显示优先级。
2. **单旋钮闭环**：旋转调速、按下开关、长按制冷——盲操可学；Pro 遥控做全功能镜像 + 定时/关屏。
3. **故障可读**：LO/HI 故障码进说明书（C6 诚实纪律延伸到售后）。

### 8.2 功耗/续航（F6 双口径）

| 工况 | 功率 | 续航(4000mAh≈14.8Wh) |
|---|---|---|
| 制冷关+静音档 | ≈0.6W | ≥24h ✓ |
| 制冷开(电池限 10W)+1档 | ≈12W | ≈1.2h ✗✗ |
| 制冷开(电池限 10W)+最低风机 | ≈11W | ≈1.3h ✗ |

> ⚠️ **架构级红灯**：F6 的"制冷开 ≥6h"在 18650×2（≤5000mAh, 18.5Wh）下**物理不成立**——10W TEC  alone 就只能跑 ~1.5h。竞品"24–48h 续航"全部是**风冷口径**。必须三选一（进 Q3）：
> a) 续航口径改为"制冷开（电池）≥1.5h / 插电不限"（诚实但详情页难看）；
> b) 电池档 TEC 限到 5W（ΔT≈−1.5°C，制冷变心理安慰，违背 C1）；
> c) 加大电池到 4×18650（重量 +95g、成本 +¥16，违反 B1）。
> **建议 a**——与 C6 一致，且"插电满功率制冷"恰是桌面场景主工况（工位有插座）。soip 的 6000 销量证明市场接受插电逻辑。
