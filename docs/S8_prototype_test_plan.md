# S8 手板验证计划（热架构与关键规格实测）

> 前置：Q1 已定 A（D-2026-08-29-01）。本计划覆盖风险登记表 R2/R3/R5/R6/R7 的闭环（architecture/product-architecture.md §10）。
> 原则：**热架构三项（降温/噪音/温升）先过，再谈外观手板**——物理风险之首是双风道热性能。
> 样机路径：ODM 功能样机（CNC/3D 打印壳 + 真实 TEC/风机/电池/PCB），数量 ≥2 台（1 台实测 1 台拆解）。

## T1 出风降温（R2，F1 核心）

| 项 | 内容 |
|---|---|
| 方法 | 热电偶（T 型，±0.5°C）置出风口几何中心；环温 25±1°C 房间；制冷+1 档运行 5min 后读数 |
| 口径 | 插电档目标 ≤ 环温 −4°C；电池档目标 ≤ 环温 −2°C（架构 §8.2 决策：电池档功率受限，详情页双口径） |
| 加测 | 数显读数 vs 热电偶比对（误差 ≤±1°C 才算 F1 的"可验证"成立）；连续 30min 漂移 |
| 退出 | 插电档 ≥4°C 温差 → 过；不达标 → 查热端散热（T3）与漏风（T5），仍不达标回架构 §3.3 重算 |

## T2 噪音（R3，F2）

| 项 | 内容 |
|---|---|
| 方法 | 半消声室（或等效安静环境本底 ≤25dB），声级计 A 计权距 30cm，正对出风口 |
| 口径 | 静音档 ≤35 dB(A)；满档 ≤48 dB(A)；各测 3 次取均值 |
| 加测 | 扫风机构（步进电机+齿轮）运转噪音单独测——齿轮啮合是已知风险源（竞品卡西道夫差评"摇头齿轮噪音"） |
| 退出 | 双口径达标 → 过；超标 → 查风机选型（FOC 正弦驱动是否真弦波）与风道啸叫（百叶角度） |

## T3 热端排热（R6，ADR-1 的物理兑现）

| 项 | 内容 |
|---|---|
| 方法 | 热像仪（或接触式热电偶 ×3：热端散热器/外壳右壁/出风口）制冷满档 30min |
| 口径 | 外壳温升 ≤15°C；热端散热器温度稳态（不持续爬升）；**冷出风口温度不被热风回流污染**（T1 读数不随时间劣化） |
| 退出 | 三项全过 → 双风道隔离成立；热风回流 → 检查隔板密封（IF-2 EVA 棉压缩量）与热排方向 |

## T4 防凝露（R5）

| 项 | 内容 |
|---|---|
| 方法 | 高湿环境（≥80%RH，加湿器+密闭箱）制冷满档 2h |
| 口径 | 出风口/冷鳍区域无可见滴水；防凝露保护（出风 ≤12°C 停 TEC）触发正常，数显报 LO |
| 退出 | 无滴水+保护正常 → 过 |

## T5 风道密封（IF-2）

| 项 | 内容 |
|---|---|
| 方法 | 烟雾笔（或香薰烟）置进风口，观察冷热两路是否串流；风压计测冷/热风道静压差 |
| 口径 | 漏风率 <5%（定性：烟雾无跨腔窜流） |
| 退出 | 无窜流 → 过；窜流 → 密封棉加厚/隔板配合面修整 |

## T6 扫风机构寿命（ADR-3 替代方案验证）

| 项 | 内容 |
|---|---|
| 方法 | 扫风连续运转老化 2 万次（约 55h），前后测摆角精度与噪音 |
| 口径 | 摆角衰减 ≤10%；无齿轮打齿/松动异响 |
| 退出 | 达标 → 导风板方案锁定；不达标 → 回设计评估齿轮模数/材料（POM→金属） |

## T7 续航双口径（R7，F6）

| 项 | 内容 |
|---|---|
| 方法 | 满电（Type-C 充至截止）→ 制冷开 1 档跑到保护关机；制冷关 1 档跑到关机 |
| 口径 | 制冷开 ≥1.5h（电池档诚实口径）；制冷关 ≥24h |
| 退出 | 双口径达标 → 详情页按实测值标注（C6） |

## 记录与反馈

- 每台样机一份《实测记录表》（日期/环境/仪器型号/原始读数照片）——数据回流 `data/` 并更新 design-spec §5 对应行的"待验证→实测值"。
- 任何一项退出条件不达标：先在 `data/decisions.json` 记录问题与处置，再改设计——不允许"差不多过了"。
