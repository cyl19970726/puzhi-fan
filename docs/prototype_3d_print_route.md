# 手板制造路线：3D 打印 + 购买件 自打样方案（v1，2026-08-30）

> 回答："是不是大部分可以 3D 打印，只有一些东西要找供应商？"
> 结论：**手板阶段——是。量产阶段——不是（注塑开模才是量产路径）。**
> 战略意义：自打样把 S8 热架构验证（T1–T7）从 ODM 谈判中解耦——不必等 NDA/报价就能先做功能样机。

## 1. 零件制造路线分级（对照 assembly_a_eng 40 件 / bom.json M1–M8）

### A 类：3D 打印（结构件，≈20 件，全部自产可行）

| 零件 | 打印工艺建议 | 注意 |
|---|---|---|
| 前壳/后壳（M6） | FDM PETG 或 SLA | 壁厚 2.0mm 可打；旋扣卡扣强度低于注塑，手板够用；分件线处留 0.2mm 余量 |
| 前面板/导风板×3（M6） | SLA（细节） | 百叶/薄壁特征 FDM 易糊，SLA 或 SLS 更稳 |
| 底座上下盖+配重袋（M1） | FDM | 配重改为灌铅砂/钢珠+环氧（替代注塑沉袋钢盘） |
| 防滑硅胶圈（M1） | **TPU 95A 打印** | 不必买，直接柔性打印 |
| 中隔板/冷热风道件（M5） | FDM **PETG/ASA，禁 PLA** | 热端侧附近温度可达 60–80°C，PLA ~60°C 软化 |
| 电池支架（M2） | FDM | 减震筋照常打印 |
| 齿轮组 m0.8（M1） | SLA 树脂或 FDM 0.12mm 层厚 | 手板啮合可用；量产换 POM 注塑 |
| 旋钮帽/制冷键帽（M3） | SLA | 手感件，类肤质后处理 |
| 数显窗框/遮光筋（M7） | SLA 黑树脂 | 半透窗单独买 PMMA 薄片切割 |

### B 类：必须购买（功能件，全部已在 bom.json 有 ✅/⚠️ 候选）

| 零件 | 候选 | 原因 |
|---|---|---|
| TEC 制冷片（M5） | 先导热电 TEC04902 ¥4.2 ✅ | 半导体器件，不可打印 |
| 冷端铝鳍/热端散热器（M5） | 俊诚 ¥1.4 / 星河 ¥12 ✅ | 导热必须金属（铝/铜），塑料打印件导热率差两个数量级 |
| 无刷风机总成（M4） | 锐泓 ¥6 ✅ | 电机不可打印；扇叶打印动平衡不达标（高速振动+噪音，T2 会挂） |
| 18650 电池组（M2） | 奕辉 ¥16 ✅ | 安全件，只买带保护板 PACK |
| **PCB 主控（M3）** | 尊智 ¥8 ✅ / 或自绘打样 | 你说得对——这是典型的"必须找供应商"项；也可打样阶段用现成开发板拼凑（见 §3） |
| 数显数码管模组（M7） | 凯越光 ✅ | 光电器件 |
| 28BYJ-48 步进电机（M1） | 博顺/东兴威 ✅ | 标准电机 |
| Type-C 母座/螺丝/线材 | 标准件 ¥2 | 淘宝/立创 |

### C 类：辅助材料

EVA 密封棉（IF-2）、导热硅脂（TEC 两面必涂）、环氧胶、PMMA 半透片——全部淘宝标准品。

## 2. 成本与周期估算（自打样 1 台功能样机）

- 打印件：≈800g 料（PETG+树脂+TPU），自家打印成本 <¥100；外发打印（嘉立创/未来工厂）≈¥300–500，3–5 天
- 购买件：BOM 核心件 ≈¥45（TEC 4.2+鳍片 1.4+风机 6+电池 16+PCB 8+数显 4+步进电机 ~3+标准件 2）+ 运费
- **单台手板总成本 ≈¥400–600，周期 ≈1 周**（vs ODM 打样通常 ¥3000–10000 + 2–3 周）
- 价值：T1–T7 实测数据（降温/噪音/温升/续航）提前拿到，带着实测数据去和 ODM 谈，议价地位完全不同

## 3. 打样阶段 PCB 的两条路

1. **快路（推荐首台）**：不用定制 PCB——ESP32/ STM32 开发板 + 现成模块拼凑：FOC 风机驱动板（SimpleFOC 类）+ TEC H 桥驱动模块 + 充电管理模块（TP4056 类带路径管理）+ 数码管模块。体积大、走线乱，但 T1–T7 全部可测。成本 ≈¥80–150，3 天到。
2. **正路**：按架构 §4 电源树自绘 PCB 发尊智或立创打样（¥50–200，5–7 天）——第二台样机用。

## 4. 与 ODM 谈判的关系

- 臻源"甲供模式"与此天然衔接：自打样验证后，甲供件清单就是我们 BOM 的 ✅ 候选（先导/锐泓/奕辉/尊智）——他们只赚开模+组装，我们捏住关键件成本。
- 自打样**不替代** ODM 手板：注塑件的手感/强度/密封与打印件不同，DFM 评审仍需 ODM 参与；自打样的定位是"热架构与规格的物理验证前置"。
- 若 T1–T7 全过且想先试水市场：可 3D 打印小批量（50–100 台）首发验证，再决定开模——开模费从"赌注"变"确认后的投资"。

## 5. 下一步动作

1. 从 assembly_a_eng.glb 导出 A 类零件的可打印网格（逐件 STL，流形检查+壁厚校核）——`cad/` 管线加一个 export_stl 步骤；
2. 按 §1-B 清单下单购买件（先导/俊诚/锐泓/奕辉/凯越光/博顺——全部是已核验候选，旺旺询价顺带要样品价）；
3. §3 快路电子件淘宝下单；
4. 装配 + 按 `docs/S8_prototype_test_plan.md` 跑 T1–T7。
